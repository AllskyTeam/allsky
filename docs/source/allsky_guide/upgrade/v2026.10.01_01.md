# Upgrade Notes for v2026.10.01_01

## Howto Upgrade

Please refer to the [installation instructions](/allsky_guide/allsky.md) on howto upgrade Allsky. Once you have upgraded to this version you can use the much simpler upgrade function outlined above for later updates

## Key features In This Release { data-toc-label="Key features" }

- Defined image stretching based upon the Moons brightness
- Ability to define how long image sare kept on local and remote websites
- Upload Keolapses to remote and local websites
- Display Keolapses in the WebUI
- Improved mask editor
- Conditional formatting of fields in the overlay editor
- Ability to read the speed of a pwm fan

## Breaking Changes

!!! pullquote ""

    There are no breaking changes in this release.
