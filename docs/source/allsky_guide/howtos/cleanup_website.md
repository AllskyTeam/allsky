The default is for Local and Remote Websites to keep all days' images, which means eventually you'll run out of disk space.  To limit the number of days of images that are kept, see below.

## Local Website { data-toc-label="Local Website" }

You can easily limit the number of days of images stored on your local Website via the ==Days To Keep on Pi Website== setting in the WebUI with the number of days of data you want to keep. Older files will be removed every morning.

## Remote Website { data-toc-label="Remote Website" }

To set the number of days of images stored on your remote Website, use the ==Days To Keep on Remote Website== setting.
